## Installation und Update

- **Windows:** EXE herunterladen und starten. Für ein Update NP-Control schliessen und die alte EXE durch die neue ersetzen. Kundenordner und Einstellungen bleiben erhalten.
- **Fedora:** `sudo dnf install ./np-control-6.4.0-1.fc45.noarch.rpm` – ein Update wird genauso installiert.

NP-Control prüft beim Start, ob hier eine neuere Version liegt, und meldet sie (abschaltbar in der Update-Meldung). Dabei werden keine Daten übertragen ausser der Abfrage der Release-Liste bei GitHub.

> Automatisch aus dem Release-Prozess erstellt. Der Teststatus jeder Version steht in ihren Versionshinweisen.
